# 🇻🇳 Phú Gia Diamond - Sales Page Việt Nam (VNĐ)

Dự án Landing Page bán hàng chuyên biệt cho thị trường Việt Nam (Thanh toán COD VNĐ, giao hàng 63 tỉnh thành).

## 📂 Cấu trúc dự án:
- `index.html`: Trang bán hàng chính tại Việt Nam (Bảng giá 1 Chiếc & 1 Đôi từ 4mm - 7.5mm, Popup xác nhận đặt hàng).
- `admin.html`: Bảng điều khiển Admin quản lý cấu hình và danh sách đơn hàng.
- `Code.gs`: Mã nguồn backend Google Apps Script.
- `images/`: Toàn bộ hình ảnh sản phẩm, kiểm định GRA, review khách hàng.

## 🚀 Hướng dẫn sử dụng:
1. Mở `index.html` trực tiếp trên trình duyệt hoặc đưa lên hosting / GitHub Pages.
2. Dán mã `Code.gs` vào Google Apps Script để nhận đơn và bắn thông báo qua Telegram/Gmail.
